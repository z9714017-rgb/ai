# 상담 접수 관리 (사내 서버용)

전화 상담 접수부터 내소·전화 후속 일정까지 관리하는 웹 도구입니다.
Node.js로 동작하며, 별도 데이터베이스 설치 없이 서버의 `data/` 폴더에
JSON 파일로 저장됩니다. 여러 명이 동시에 접속해서 입력·조회할 수 있고,
다른 사람이 입력한 내용은 최대 4초 안에 자동으로 화면에 반영됩니다.

## 실행 방법

```bash
npm install
npm start
```

기본적으로 3000번 포트에서 실행됩니다. 다른 포트를 쓰려면:

```bash
PORT=8080 npm start
```

실행 후 사내망에서 다음 주소로 접속하면 됩니다.

```
http://<서버의 사내 IP 또는 호스트명>:3000
```

(방화벽에서 해당 포트를 열어줘야 다른 PC에서 접속할 수 있습니다.)

## 데이터 저장 위치

- `data/intakes.json` — 상담 접수 기록 전체
- `data/staff.json` — 담당자 목록

두 파일 모두 사람이 읽을 수 있는 JSON 텍스트입니다. 백업하려면 이
`data/` 폴더를 통째로 복사해두면 됩니다. (서버를 껐다 켜도 데이터는
그대로 유지됩니다.)

## 계속 켜두기 (선택)

터미널을 닫아도 서버가 계속 돌아가게 하려면 [pm2](https://pm2.keymetrics.io/)
같은 프로세스 매니저를 쓰는 걸 권장합니다.

```bash
npm install -g pm2
pm2 start server.js --name intake
pm2 save
pm2 startup   # 서버 재부팅 시 자동 시작 (안내되는 명령어 실행)
```

## 참고

- 화면 폰트는 Google Fonts(웹 폰트)를 CDN에서 불러옵니다. 사내 서버가
  외부 인터넷 접속이 안 되는 환경이라면 폰트만 시스템 기본 폰트로
  자동 대체되어 보이고, 기능에는 문제가 없습니다.
- 이 도구는 소규모 내부 사용을 전제로 만들어졌습니다(동시 접속자가
  많지 않다는 가정하에 파일 기반으로 저장). 이용 인원이 크게 늘어나면
  정식 데이터베이스(MySQL/PostgreSQL 등)로 옮기는 걸 권장합니다.
